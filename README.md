# Dylan的个人博客

基于 Jekyll + [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) 主题的个人静态博客，托管于 GitHub Pages。

- 线上地址：<https://dylan111011.github.io/>
- 文章目录：`_posts/`（文件名格式 `YYYY-MM-DD-标题.md`）
- 站点配置：`_config.yml`

## 写新文章

在 `_posts/` 下新建 Markdown 文件，例如 `2026-10-08-my-post.md`：

```markdown
---
title: 文章标题
date: 2026-10-08
categories: blog
tags: [随笔]
---

正文内容（Markdown）……
```

提交并推送到 `main` 分支后，GitHub Pages 会自动构建发布。
